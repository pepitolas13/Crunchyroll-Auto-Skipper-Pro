Privacy Policy

Extension: Crunchyroll Auto-Skipper Pro

Last updated: May 6, 2026

Summary: This extension operates 100% locally in your browser. It DOES NOT collect, store, transfer, or sell any personal data or browsing history.

1. Data Collection

Crunchyroll Auto-Skipper Pro is designed with user privacy as the top priority. The extension does not collect any personal information, IP addresses, viewing history, or any other user data.

2. Local Storage

The extension strictly uses the browser's local storage API (chrome.storage.local) to save your configuration preferences. This includes:

  • The state of the menu toggles (e.g., whether you have enabled or disabled the skipping of intros, recaps, or next episodes).
  • The selected language for the extension's interface.

This data is stored exclusively on your local device. The developer does not have access to this data, and it is never sent to any external servers.

3. Host Permissions

The extension requires permission to run on *://*.crunchyroll.com/*. This permission is strictly necessary to:

  • Inject the script that reads the Crunchyroll video player.
  • Visually detect when the "Skip" buttons appear.
  • Automatically click those buttons based on your preferences.

This process happens locally and in real-time on your computer. We do not track or log what shows or episodes you are watching.

4. Changes to this Policy

We may update this privacy policy in the future. Any changes will be posted on this page. However, our core commitment to not collecting user data will always remain.

5. Contact

If you have any questions regarding this privacy policy, you can contact us through the Chrome Web Store support section or by creating an "Issue" in the project's official GitHub repository.
